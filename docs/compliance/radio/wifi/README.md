# wifi

Parte del Technical File di conformità ARALD (vedi `docs/compliance.md`, §15). **Vuota per ora**: nessun hardware ARALD Card/Clip/Fixed Relay/Box/Portable esiste ancora fisicamente in questo progetto.

Parametri radio Wi-Fi effettivamente usati (canale/i, potenza, modalità STA/SoftAP, quando si attiva il SoftAP on-demand) — ereditati dal modulo Arduino Nano ESP32 ABX00092 (ESP32-S3), stessa antenna del BLE — vedi `docs/compliance.md` §3 e `docs/beacon.md`, sottosezione "Wi-Fi: terzo radio, non più escluso".
