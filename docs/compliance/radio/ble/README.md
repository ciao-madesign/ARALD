# ble

Parte del Technical File di conformità ARALD (vedi `docs/compliance.md`, §15). **Vuota per ora**: nessun hardware ARALD Card/Clip/Fixed Relay/Box/Portable esiste ancora fisicamente in questo progetto.

Parametri radio BLE — ereditati dal modulo Arduino Nano ESP32 ABX00092 (ESP32-S3), non un chipset scelto separatamente (versione stack, potenza, canali, antenna integrata sul modulo) — vedi `docs/compliance.md` §3, e `radio/wifi/` per il terzo radio che condivide lo stesso chip/antenna.
