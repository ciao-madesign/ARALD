Open-source mesh network

The internet ends.
ARALD doesn't.

Phones, small radios, and local computers pass messages, content, and services directly to each other — no towers, no satellite link, no connection required.

The idea, in one request

Ask for what you need.
Not where it is.

No signal at a mountain hut? Ask for the page you want — the network finds a path between devices and delivers it, the same way a letter reaches you without you knowing which trucks carried it.
