# tests/dtn/

Questa directory specifica resta vuota — non perché la funzionalità manchi, ma perché i test di delay-tolerant networking (store-and-forward, courier, partition sync — Milestone 12-13, spec §30-34, §72-73) sono già stati scritti sotto `tests/integration/` invece che qui: `store-and-forward.test.ts`, `store-and-forward-relay-gate.test.ts`, `partition-sync.test.ts`. La coda di consegne pendenti (`node/src/store-and-forward.ts`, `PendingDeliveryQueue`) è implementata e testata da tempo. Nessun lavoro reale in sospeso qui — solo una directory segnaposto mai popolata perché la convenzione del progetto ha finito per raggruppare tutti i test di integrazione in un unico posto.
